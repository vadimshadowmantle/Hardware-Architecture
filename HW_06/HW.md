# Компьютерное железо: HDD vs SSD и термины памяти

## Сравнительная таблица: HDD и SSD

| Параметр | HDD | SSD |
|---|---|---|
| **Принцип работы** | Магнитная запись на вращающиеся пластины (магнитные диски) с помощью головок чтения/записи | Запись электрических зарядов в ячейках флеш-памяти (NAND); нет механики |
| **Скорость чтения/записи (примерно)** | 80–160 МБ/с (последовательная); случайный доступ очень медленный (мс) | SATA: 500–550 МБ/с; NVMe: 2000–7000+ МБ/с; случайный доступ — микросекунды |
| **Наличие движущихся частей** | Есть (шпиндель, пластины, головки) | Нет (полностью электронный) |
| **Устойчивость к ударам** | Низкая — при работе чувствителен к тряске/ударам | Высокая — нет механики, удары почти не страшны |
| **Уровень шума** | Слышимый (шум вращения и позиционирования головок) | Бесшумный |
| **Цена за 1 ТБ** | Дешевле (примерно 2–4 тыс. ₽ за 1 ТБ, зависит от рынка) | Дороже (примерно 5–10 тыс. ₽ за 1 ТБ) |
| **Срок службы / ограничения** | Ограничен механикой; ресурс — годы, но боится тряски; число циклов записи не критично | Ограничен ресурсом ячеек (TBW); при исчерпании — деградация; в целом 5–10 лет |
| **Пример использования** | Архивы, бэкапы, медиатека, серверы хранения, недорогие ПК | ОС и программы, игры, ноутбуки, серверы с высокой нагрузкой на случайный доступ |

## Определения терминов

1. **DDR** — *Double Data Rate* («двойная скорость передачи данных»). Тип оперативной памяти, в котором данные передаются как по фронту, так и по спаду тактового сигнала, то есть за один такт выполняется две передачи — вдвое быстрее по сравнению с обычной SDR-памятью.

2. **DIMM** — *Dual In-line Memory Module* — модуль оперативной памяти с двумя рядами контактов (по обе стороны платы), устанавливаемый в слоты на материнской плате. Стандартный формат модулей для настольных ПК и серверов (в ноутбуках — SO-DIMM).

3. **Ранг (rank)** — логическая группа микросхем памяти на модуле, которые одновременно обслуживаются одним обращением (за один такт выбирается целиком). Модуль может быть одноранговым (single-rank), двухранговым (dual-rank) и т.д. Ранг влияет на нагрузку на контроллер памяти и на совместимость/производительность.

4. **CAS Latency (CL)** — задержка доступа к столбцу (*Column Address Strobe Latency*): число тактов между подачей команды чтения и моментом, когда данные становятся доступны. Показывает, насколько «медленно» память откликается на запрос; чем меньше CL, тем лучше (при той же частоте).

5. **Тайминги** — набор задержек (в тактах) при обращении к памяти: CL, tRCD, tRP, tRAS и др. Они описывают, сколько тактов нужно памяти на выполнение различных операций (выбор строки, столбца, закрытие строки). Меньшие тайминги = более быстрый отклик, но обычно при более низкой частоте.

6. **Двухканальный режим** — режим работы, при котором два модуля памяти работают параллельно через два канала контроллера. Нужен для увеличения пропускной способности памяти (теоретически вдвое), что особенно важно для встроенной графики и задач с интенсивным обменом данными (игры, рендеринг, серверы). Для его работы модули обычно ставятся в определённые пары слотов (например, A1+B1).
