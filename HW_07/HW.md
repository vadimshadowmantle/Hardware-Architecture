# Решение: «Сборка и диагностика ПК без BIOS и доп. программ»

**Выбран набор A:** i5-13600K + ATX B760 + 2×16 ГБ DDR5-6000 + RTX 4070.

---

## Задание 1

**1.1.** По форм-фактору не отпадает ни один набор. ATX (305×244 мм) и mATX (244×244 мм) входят в Mid-Tower с поддержкой ATX/mATX/Mini-ITX: меньшие платы крепятся на часть тех же стоек. Проверить стоит только длину GPU и высоту кулера.

**1.2.** Не подходит **B**. Второй M.2 у него Key E (под Wi-Fi), NVMe с ключом M туда не вставить. Слот x16 занят GPU, x1 — звуковой картой. Переходник M.2→PCIe ставить некуда, а переходник в Key E даёт максимум x1 (или только CNVi) и обычно не позволяет загружаться с диска.

**1.3.** Расчёт: A = 181 + 200 + 50 = **431 Вт**, B = 142 + 200 + 50 = **392 Вт**, C = 65 + 115 + 50 = **230 Вт**. По мощности 650 Вт хватает всем. Узкие места — разъёмы:
- у A на плате EPS 8+4, а у БП только один 8-pin (для 181 Вт этого достаточно, см. 3.3);
- в условии у БП не указаны кабели PCIe для GPU. Для 12VHPWR (A, B) нужен переходник с 2×PCIe 8-pin, это надо проверить.

**1.4.** Из A и C выбран **A**:
- **VRM:** 12+1 фаз на 181 Вт — примерно 12 А на фазу, перегрева нет. У C 6+1 фаз, апгрейда процессора эта плата не потянет.
- **XMP/EXPO:** B760 поддерживает XMP, память работает на 6000 CL30. H610 разгон памяти не поддерживает, да и 16 ГБ DDR4 для 1440p со стримом мало.
- **Линии PCIe:** у A от CPU идут x16 Gen5 и x4 Gen4, а чипсет даёт ещё M.2 Gen4, слот x4 и 2 слота x1. У C свободен только один x1.

## Задание 2

**2.1.**

| Устройство | Слот | Источник | Версия | Линии |
|---|---|---|---|---|
| GPU | PCIEX16_1 | CPU | Gen4 (карта Gen4) | x16 |
| NVMe №1 | M.2_1 | CPU | Gen4 | x4 |
| Звуковая карта | PCIe x1 | Chipset | по версии карты | x1 |
| NVMe №2 | M.2_2 | Chipset | Gen4 | x4 |

**2.2.** Физически влезет, электрически заработает на x1 со скоростью, которую поддерживает карта. Правило «больше — можно, меньше — нельзя»: короткую карту можно ставить в длинный слот, наоборот — нет. Связь устанавливается по меньшему числу линий и меньшей версии.

**2.3.** Чипсет связан с CPU через **DMI 4.0 x4** (~7,9 ГБ/с). NVMe №2 (~7 ГБ/с), сеть 2.5G и USB 3.2 делят этот канал, и при одновременной нагрузке он становится «бутылочным горлышком». Поэтому систему и игры лучше держать на NVMe №1 от CPU.

**2.4.** Нет. На плате A слота Key E нет. Key E — это PCIe x1, USB и CNVi под Wi-Fi/BT, а NVMe нужен Key M (PCIe x4): ключи физически разные.

## Задание 3

**3.1.** Дежурное питание +5VSB есть → после нажатия кнопки плата опускает PS_ON# → БП запускает линии 12/5/3,3 В. Сигнал PWR_OK не приходит, поэтому чипсет держит CPU в сбросе. Итог: вентиляторы и подсветка включаются, но **POST не начинается**, изображения нет, возможен циклический перезапуск.

**3.2.** При 181 Вт и ~1,3 В ток составляет ~140 А. При 12 фазах это ~12 А на фазу: малый нагрев, ровное напряжение. На плате 6+1 будет ~23 А на фазу, а потери ∝ I², поэтому VRM перегреется до 100+ °C. Начнётся троттлинг или срежутся лимиты мощности, частоты упадут, возможны нестабильность и деградация компонентов.

**3.3.** Подключить только 8-pin можно. 181 Вт / 12 В ≈ 15 А, то есть ~3,8 А на каждый из 4 контактов при допустимых 7–9 А (~235–300 Вт на разъём). В турбо последствий нет, разъём не перегревается. Дополнительный 4-pin нужен только для разгона.

**3.4.**
- **ATX 24-pin** — питание всей платы: +3,3/+5/+12/−12 В, +5VSB, сигналы PS_ON# и PWR_OK.
- **EPS 8-pin** — только +12 В на VRM процессора.

В 24-pin всего две линии +12 В (~150 Вт), и их уже делят слоты PCIe и прочая периферия. CPU нужно >100 А, которые VRM получает из 12 В рядом с сокетом.

## Задание 4

**4.1.** Без включённого профиля память работает по JEDEC из SPD: **DDR5-4800 CL40, 1,1 В**. XMP — это разгон сверх стандарта, поэтому по умолчанию он выключен.

**4.2.**
- **Слоты:** 4 есть, но получится 2 модуля на канал (2DPC).
- **Частота:** нагрузка на шину вдвое выше и появляются отражения сигнала. Реально будет 4400–5600 вместо 6000.
- **IMC:** контроллеру нужны повышенные напряжения, и результат зависит от экземпляра CPU.

Лучше купить комплект 2×32 ГБ.

**4.3.** Нельзя. Ключ (вырез) стоит в другом месте, поэтому модуль физически не войдёт. Электрически тоже несовместимо: DDR4 питается 1,2 В от платы, а у DDR5 стоит собственный PMIC на модуле, другая распиновка и подканалы.

**4.4.** При тренировке UEFI читает SPD, выставляет частоту и тайминги, калибрует ODT, Vref и задержки DQS и прогоняет тесты. Если на частоте EXPO/XMP стабильного окна нет, после нескольких попыток плата откатывается на JEDEC: **DDR5-4800**.

## Задание 5

**5.1.**
- **Smart Fan** — кривая для CPU_FAN: до 50 °C — 25–30 %, 70 °C — 60 %, 85 °C — 100 %, сглаживание 3–5 с.
- **Zero RPM** — для корпусных вентиляторов: стоп ниже 40 °C, старт при 45 °C.

Под нагрузкой вентиляторы выходят на 100 %, производительность не страдает.

**5.2.** Adaptive Voltage подаёт напряжение по кривой только под нагрузкой. Андервольт сдвигает эту кривую на −50…−80 мВ. Эффект: **−7…−12 °C** под нагрузкой, частота стабильно держится на ~5,1 ГГц (**+100–200 МГц** удержания вместо упора в лимиты). Перед этим обновить BIOS (микрокод 0x12B+ для 13-го поколения).

**5.3.** Шаги:
1. Флешка FAT32, на ней файл BIOS для своей модели платы, переименованный по инструкции (например, `MSI.ROM`).
2. Подключить 24-pin и EPS, включить БП. CPU не нужен.
3. Вставить флешку в порт BIOS Flashback и удерживать кнопку ~3 с.
4. Индикатор мигает 3–8 мин. Когда погаснет, прошивка готова.

**5.4.** Zero RPM — нижний участок той же кривой Smart Fan: ниже T_stop скорость 0 %, выше T_start — обычная кривая. Гистерезис между порогами не даёт вентилятору дёргаться. Если порог выше критической температуры VRM, вентиляторы будут стоять при перегретом VRM: начнётся троттлинг, а в худшем случае аварийное отключение.

## Задание 6

| № | Диагноз | Решение |
|---|---|---|
| 6.1 | По размерам mATX влезает, мешают стойки, заглушка I/O или кабели | Переставить стойки под mATX, сначала поставить заглушку I/O |
| 6.2 | GPU работает на x4 от чипсета через DMI | Переставить в верхний x16 от CPU |
| 6.3 | 2DPC: IMC не держит частоту EXPO | Комплект 2×32 ГБ или снизить частоту до 5200–5600 |
| 6.4 | VRM 6+1 не рассчитан на ~140 А | Плата с VRM 12+1 или ограничить PL1/PL2 |
| 6.5 | Старый BIOS без поддержки Ryzen 9000 (AGESA 1.2.0.x+) | BIOS Flashback без CPU |
| 6.6 | Нет управления PWM: вентилятор в 3-pin или PUMP-разъёме, режим Full speed | Подключить к CPU_FAN 4-pin, режим PWM, Smart Fan |
| 6.7 | Слот x4 делит линии с M.2_2 или SATA, либо карта вставлена не до конца | Перенести в отдельный x1, переустановить карту |

## Задание 7. Схема (набор A)

```
БП 650 Вт (~431 Вт)
 ├─ ATX 24-pin ──────────► ATX_PWR
 ├─ EPS 8-pin ───────────► EPS_8PIN   (EPS_4PIN не подключён — нужен только для разгона)
 └─ 2×PCIe 8-pin → 12VHPWR ► RTX 4070 (проверить наличие кабелей у БП)

CPU i5-13600K
 ├─ x16 Gen5 ─► PCIEX16_1: RTX 4070 (Gen4 x16) — только сюда, это линии CPU
 ├─ x4 Gen4 ──► M.2_1: NVMe №1 (система, игры)
 └─ DMI 4.0 x4 ─► Чипсет B760   ⚠ общий канал на всё ниже
                   ├─ M.2_2: NVMe №2 (будущий) ⚠ может делить линии со слотом x4/SATA
                   ├─ PCIEX16_2 (x4): резерв ⚠ не для GPU
                   ├─ PCIEX1: звуковая карта — не перекрыт GPU, x1 достаточно
                   └─ LAN 2.5G, USB, SATA

RAM: A2 + B2 — 2×16 DDR5-6000, XMP ⚠ без XMP 4800; 4 модуля — 6000 не держит
CPU_FAN (4-pin): башня, Smart Fan, мин. 25 % ⚠ кулер 180 Вт ≈ PL2 181 Вт — впритык
SYS_FAN1/2 (4-pin): Smart Fan + Zero RPM < 40 °C
4-pin = отдельный ШИМ-сигнал: точная регулировка и возможность остановки вентилятора.
```
